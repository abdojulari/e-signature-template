# Google SEO Setup for SignaturePro

## 🔍 Google Search Console Setup

### Step 1: Add Your Site to Google Search Console

1. **Go to Google Search Console**: https://search.google.com/search-console
2. **Click "Add Property"**
3. **Enter your domain**: `signature-pro.ca`
4. **Choose verification method**:

#### Option A: HTML Meta Tag (Recommended)
1. Google will provide a meta tag like: `<meta name="google-site-verification" content="YOUR_CODE_HERE" />`
2. Add this to your Nuxt config (I'll help you with this)

#### Option B: HTML File Upload
1. Google will provide an HTML file to download
2. Upload it to your `/public` folder
3. I can help you add this file

### Step 2: Submit Your Sitemap

Once verified:
1. Go to "Sitemaps" in the left sidebar
2. Add sitemap URL: `https://signature-pro.ca/sitemap.xml`
3. Click "Submit"

### Step 3: Request Indexing

1. Go to "URL Inspection" 
2. Enter: `https://signature-pro.ca`
3. Click "Request Indexing"
4. Repeat for: `https://signature-pro.ca/dashboard`
