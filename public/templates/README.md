# Template Preview Images

This folder contains preview images for each signature template that are displayed in the template selection interface.

## Quick Setup

### Option 1: Use the Preview Generator (Recommended)
1. Open `generate-previews.html` in your browser
2. Take a screenshot of each template section 
3. Crop and resize each screenshot to **300x150px**
4. Save them as PNG files with the exact names shown
5. Replace the placeholder files in this folder

### Option 2: Use Pre-made Images
You can also create your own preview images using design tools like:
- **Figma** - Create template mockups
- **Canva** - Use signature templates
- **Photoshop** - Design custom previews
- **Online Screenshot Tools** - Capture live templates

## Required Files

Each file should be **300x150px PNG format**:

- `minimal-preview.png` - Clean, simple design
- `professional-preview.png` - Corporate business style  
- `creative-preview.png` - Bold gradient background
- `glassmorphism-preview.png` - Modern glass effect
- `modern-preview.png` - Contemporary sleek design
- `elegant-preview.png` - Sophisticated refined style
- `social-first-preview.png` - Profile-focused with social links
- `compact-pro-preview.png` - Compact professional layout
- `vibrant-preview.png` - Colorful and energetic design
- `executive-preview.png` - Classic business leadership style
- `handwritten-preview.png` - Personal script signature style
- `corporate-elite-preview.png` - Premium executive with gold accents

## Tips for Best Results

- **Consistent sizing**: All images should be exactly 300x150px
- **Good contrast**: Make sure text is readable in thumbnails
- **Representative**: Show the key visual elements of each template
- **Quality**: Use PNG format for crisp edges and transparency
- **File names**: Must match exactly (case-sensitive)

## Testing

After adding your images:
1. Restart the dev server (`npm run dev`)
2. Go to the dashboard template selection
3. Verify all previews load correctly
4. Check that they look good at the displayed size
